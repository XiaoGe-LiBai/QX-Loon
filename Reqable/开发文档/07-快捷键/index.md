# 快捷键

Reqable支持大量的快捷操作，按照功能分为下面几个类别：
- [Tabs操作](#tabs)
- [侧边栏](#sidebar)
- [调试控制](#capture-exec)
- [调试列表](#capture-list)
- [API请求](#rest)
- [编辑器](#editor)
- [规则列表](#rule-list)
- [其他](#others)

> ℹ️ **说明**
>
> 本文档列出的快捷键可能不完整，具体请留意应用内的快捷键提示。


### Tabs操作
| 说明 | 按键 |
| ---- | ---- |
| 新建API         | <kbd>Control + T</kbd> |
| 关闭当前Tab      | <kbd>Control + W</kbd> |
| 关闭全部Tab      | <kbd>Shift + Control + W</kbd> |
| 按照索引切换Tab   | <kbd>Control + 1/2/3/4/5/6/7/8/9</kbd> |
| 切换到右侧Tab    | <kbd>Control + 0</kbd> |
| 向左切换Tab    | <kbd>Control + [</kbd> |
| 向右切换Tab    | <kbd>Control + ]</kbd> |
| 切换到上一次的Tab    | <kbd>Control + -</kbd> |
